# Service Human Library

The Library is the permanent public knowledge archive for Service Human.

This directory is intended to house educational resources that explain ideas, frameworks, operational concepts, talks, articles, briefings, and reference materials developed by Service Human.

The Library is not social media.

It is the canonical source for long-form educational content.

Social platforms may distribute ideas.

The Library preserves them.

Knowledge remains accessible.

Knowledge remains organized.

Knowledge remains available.
